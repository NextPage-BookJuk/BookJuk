## 1. 프로젝트 비전

### 🎨 **미션 (Mission)**
> "독서를 통해 사람들을 연결하고, 지식 공유의 즐거움을 확산시킨다"

### 🌟 **비전 (Vision)**
> "국내 최고의 오프라인 독서모임 플랫폼이 되어, 독서 문화 활성화에 기여한다"

### ⚡ **핵심 가치 (Core Values)**
- **연결 (Connection)**: 책을 매개로 한 진정한 인간관계 형성
- **성장 (Growth)**: 함께 읽고 토론하며 지적 성장 추구
- **신뢰 (Trust)**: 안전하고 신뢰할 수 있는 모임 환경 제공
- **다양성 (Diversity)**: 다양한 장르와 관점의 책을 통한 포용성
- **지속성 (Sustainability)**: 꾸준한 독서 습관 형성 지원

## 2. 핵심 가치 제안

### 🎯 **주요 페인포인트 해결**

#### **문제점 1: 혼자 읽는 독서의 한계**
- **해결책**: 함께 읽고 토론할 수 있는 모임 제공
- **가치**: 더 깊이 있는 이해와 다양한 관점 획득

#### **문제점 2: 독서모임 찾기의 어려움**
- **해결책**: 지역/장르별 맞춤형 모임 추천
- **가치**: 내 취향과 일정에 맞는 모임 쉽게 발견

#### **문제점 3: 모임 운영의 복잡성**
- **해결책**: 체계적인 모임 관리 도구 제공
- **가치**: 호스트의 운영 부담 최소화

#### **문제점 4: 신뢰할 수 있는 참여자 확인 어려움**
- **해결책**: 리뷰 시스템을 통한 신뢰도 관리
- **가치**: 안전하고 질 높은 모임 경험

### ✨ **차별화 포인트**
1. **오프라인 중심**: 진짜 만남과 소통에 집중
2. **간편한 운영**: 복잡한 기능 없이 핵심에만 집중
3. **지역 기반**: 접근성 좋은 근거리 모임 매칭
4. **신뢰 시스템**: 좋아요 기반 참여자 신뢰도 관리

## 3. 타겟 사용자

### 👥 **주요 사용자층**

#### **1차 타겟: 독서 애호가 (25-40세)**
- **특징**: 꾸준한 독서 습관, 토론 욕구 강함
- **니즈**: 깊이 있는 독서 경험, 지적 자극
- **행동 패턴**: 월 2-4권 독서, SNS 활동 활발

#### **2차 타겟: 독서 입문자 (20-35세)**
- **특징**: 독서 습관 형성 중, 동기부여 필요
- **니즈**: 독서 습관 형성, 책 추천
- **행동 패턴**: 월 1-2권 독서, 가이드 필요

#### **3차 타겟: 모임 리더 (30-50세)**
- **특징**: 리더십 경험, 커뮤니티 운영 관심
- **니즈**: 모임 운영 도구, 멤버 관리
- **행동 패턴**: 능동적 참여, 장기간 활동

### 🎭 **사용자 페르소나**

#### **📚 김독서 (32세, 직장인)**
- **배경**: 마케팅 회사 과장, 강남 거주
- **목표**: 업무 스트레스 해소, 새로운 관점 습득
- **페인포인트**: 혼자 읽으면 집중 안됨, 토론 상대 부재
- **사용 시나리오**: 주말 오후 강남/서초 지역 모임 참여

#### **📖 이성장 (28세, 대학원생)**
- **배경**: 인문학과 석사과정, 신촌 거주
- **목표**: 논문 작성 도움, 학술적 토론
- **페인포인트**: 전공 관련 깊이 있는 토론 기회 부족
- **사용 시나리오**: 평일 저녁 신촌/홍대 지역 철학/인문학 모임

#### **📝 박호스트 (35세, 프리랜서)**
- **배경**: 작가 지망생, 마포 거주
- **목표**: 독서모임 운영, 네트워킹
- **페인포인트**: 모임 관리 도구 부족, 멤버 모집 어려움
- **사용 시나리오**: 월 2회 정기 모임 개최, 신규 멤버 관리

## 4. 핵심 기능

### 🔥 **MVP 핵심 기능 (Phase 1)**

#### **📱 사용자 관리**
- 간편 회원가입/로그인 (JWT 인증)
- 프로필 관리 (선호 장르, 자기소개)
- 리뷰 기반 신뢰도 시스템

#### **🏠 모임 관리**
- 모임 생성/수정/취소
- 지역/장르/시간별 필터링
- 참가 신청/승인/거절 시스템

#### **💬 소통 기능**
- 모임별 게시판 (참여자 전용)
- 댓글 시스템
- 실시간 상태 업데이트

#### **⭐ 신뢰 시스템**
- 모임 후 좋아요 리뷰
- 호스트/참여자 신뢰도 표시
- 1회 제한, 취소 불가 정책

### 🚀 **확장 기능 (Phase 2+)**
- 📱 모바일 앱
- 🔔 실시간 알림
- 🗺️ 지도 연동
- 💰 결제 시스템
- 📊 통계 대시보드

## 5. 기술적 특장점

### ⚙️ **기술 스택 선택 이유**

#### **백엔드: Spring Boot + JPA + QueryDSL**
- **장점**: 안정성, 생산성, 확장성
- **이유**: 15일 개발 기간 내 MVP 완성 최적화

#### **프론트엔드: Thymeleaf + JavaScript**
- **장점**: 빠른 구현, SSR 지원, SEO 최적화
- **이유**: 복잡한 SPA 대신 실용적 접근

#### **데이터베이스: MariaDB (FK 제약 제거)**
- **장점**: 유연성, 개발 속도, 확장성
- **이유**: 애플리케이션 레벨 무결성 보장

### 🏗️ **아키텍처 특징**
- **계층형 아키텍처**: 명확한 책임 분리
- **도메인 중심 설계**: 비즈니스 로직 집중
- **API 우선 설계**: 향후 모바일 앱 확장 고려
- **테스트 친화적**: 의존성 주입, 모킹 지원

### 🔒 **보안 및 성능**
- **JWT 인증**: Stateless, 확장성 우수
- **인덱스 최적화**: 검색 성능 향상
- **에러 처리**: 일관된 예외 처리 시스템
- **입력값 검증**: 다층 보안 검증

## 6. 비즈니스 모델

### 💰 **수익 모델 (향후 계획)**

#### **1단계: 무료 서비스 (사용자 확보)**
- 모든 기능 무료 제공
- 사용자 기반 확대에 집중

#### **2단계: 프리미엄 서비스**
- **개인**: 월 3,000원 (모임 생성 무제한, 우선 신청)
- **호스트**: 월 5,000원 (고급 관리 도구, 통계 제공)

#### **3단계: 파트너십**
- **서점 제휴**: 도서 할인 혜택
- **카페 제휴**: 모임 장소 할인
- **출판사 협업**: 신간 프로모션

#### **4단계: 광고 수익**
- **도서 추천**: 맞춤형 도서 광고
- **문화 이벤트**: 독서 관련 이벤트 홍보

### 📈 **성장 전략**
1. **지역별 확산**: 서울 → 수도권 → 전국
2. **장르별 세분화**: 전문 독서모임 지원
3. **기업 연계**: 직장 독서모임 서비스
4. **교육 기관 협력**: 대학/도서관 파트너십

## 7. 경쟁사 분석

### 🏢 **직접 경쟁사**

#### **소모임 (SoMoim)**
- **장점**: 다양한 모임 카테고리, 큰 사용자 기반
- **단점**: 독서 특화 기능 부족, 복잡한 UI
- **차별점**: 독서 전용 플랫폼으로 특화

#### **번개팅**
- **장점**: 간편한 모임 생성, 지역 기반 매칭
- **단점**: 독서모임 지원 기능 한정
- **차별점**: 독서 토론에 최적화된 도구

### 🔄 **간접 경쟁사**

#### **네이버 카페**
- **장점**: 기존 사용자 기반, 다양한 기능
- **단점**: 오프라인 모임 관리 도구 부족
- **차별점**: 오프라인 모임에 특화된 UX

#### **밴드 (BAND)**
- **장점**: 그룹 관리 기능, 모바일 최적화
- **단점**: 독서모임 특화 기능 없음
- **차별점**: 독서 중심 커뮤니티 기능

### 🎯 **경쟁 우위 요소**
1. **독서 특화**: 오직 독서모임만을 위한 플랫폼
2. **간편함**: 복잡한 기능 배제, 핵심에만 집중
3. **신뢰성**: 리뷰 시스템 기반 안전한 모임
4. **지역 중심**: 접근성 좋은 오프라인 모임

## 8. 팀 구성

#### **데이터베이스 설계**
- **역할**: 스키마 설계, 성능 튜닝
- **기술**: MariaDB, 인덱스 최적화
- **책임**: 데이터 모델링, 쿼리 최적화

### 🎯 **협업 방식**
- **개발 방법론**: 애자일 스크럼
