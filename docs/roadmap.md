## 🎯 프로젝트 개요

**BookJuk 오프라인 독서모임 플랫폼**을 풀스택 개발자들이 기능별로 분담하여 15일간 개발하는 로드맵입니다.

### 📋 개발 범위
- **백엔드**: Spring Boot, JPA, MySQL
- **프론트엔드**: React, TypeScript, Tailwind CSS
- **핵심 기능**: 사용자 관리, 모임 생성/참여, 게시판, 리뷰 시스템

### 👥 팀 구성 및 작업 방식
- **풀스택 개발자들**: 각자 담당 기능의 백엔드 + 프론트엔드 통합 개발
- **기능별 분담**: 개발자별로 완전한 기능 단위를 처음부터 끝까지 담당
- **협업 방식**: 공통 설계 → 개별 기능 개발 → 통합 및 테스트

## 🔧 기능별 담당 분배

**담당자: 신동준**

- JWT 토큰 관리, 프로필 기본 관리

**담당자: 진도희**
