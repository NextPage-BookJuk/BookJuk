# 📋 2025년 8월 20일 팀 회의록 - 북적북적 프로젝트

### 1. 개요

* 발표 이틀 전, 전체 팀원이 모여 **통합 테스트**를 진행.
* 테스트 과정에서 발견된 **이슈들을 공유 및 수정**, 내일 다시 최종 테스트 진행하기로 결정.
* **발표용 PPT 제작** 진행: 이미지 중심 구성, 직관적인 전달을 위해 팀원들이 협업.
* **ERD, 간트차트, 기존 문서들 수정 및 최신화** 완료.

---

### 2. 주요 변경사항

#### 2.1 test: 전체 기능 통합 테스트 진행 및 이슈 수정

* **개요**

  * 회원가입 → 로그인 → 모임 생성 → 참여 신청 → 게시판/리뷰 기능 전체 플로우 검증.
* **변경 사항**

  * 테스트 중 발견된 UI/버그 수정.
  * 데이터 흐름 검증 및 오류 로그 확인.
* **테스트**

  * 기능별 실제 사용자 시나리오를 기반으로 수동 테스트 수행.

---

#### 2.2 docs: 발표용 PPT 제작 및 시각 자료 보강

* **개요**

  * 발표용 PPT 초안 완성, 이미지 중심으로 구성.
* **변경 사항**

  * 다이어그램(ERD, 간트차트) 최신화 및 삽입.
  * API 명세서, DDL 등 기존 문서 보완 및 최신화.
* **테스트**

  * 발표 흐름에 맞춰 슬라이드 검토, 팀원별 분량 점검.

---

#### 2.3 refactor: 문서 및 산출물 최신화

* **개요**

  * 프로젝트 산출물(요구사항 명세서, API 스펙, ERD, DDL 등) 최신 상태 반영.
* **변경 사항**

  * 기존 문서에서 누락된 부분 보완.
  * 발표 시 활용할 수 있도록 문서 구조 정리.
* **테스트**

  * 팀원들 간 상호 리뷰를 통해 문서 일관성 검증.
