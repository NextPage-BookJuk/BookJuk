# 📋 2025년 8월 18일 팀 회의록 - 북적북적 프로젝트

### 1. 개요

* **마이페이지 API/화면**, **인증 UX 개선**, **사진 업로드 연동**, **모임 목록 카드 개선(호스트 좋아요 수/장소 표기)** 등 프런트·백엔드 통합 개발 현황 공유.
* 완료 기능 확인 및 테스트/문서화 범위 정리.

### 2. 주요 변경사항

#### 2.1 feat: 마이페이지 API 컨트롤러 기능 구현 및 테스트 (#91)

* **개요**

  * 마이페이지 기능 구현을 위한 **`MyPageController`** 작성 및 테스트 완료
* **변경 사항**

  * `MyPageController` 클래스 생성(조회/수정 엔드포인트)
  * `User` 엔티티에 **`updateProfile(...)` 편의 메서드** 추가(프로필 필드 부분 갱신)
  * 요청 DTO **`UpdateProfileRequest`** 생성(닉네임/소개/프로필 이미지 등)
  * 응답 DTO **`UpdateProfileResponse`** 생성(DB update 결과 반영)
  * `MyPageService`에 **수정 비즈니스 로직** 추가(검증 → 업데이트 → 응답 변환)
* **테스트 방법/현황**

  * 서비스 단 단위 테스트(필드별 업데이트/유효성 경계값)
  * 컨트롤러 MockMvc 테스트(인증/비인증, 성공/실패 응답 포맷)

---

#### 2.2 Feat: 사진 업로드 시 백엔드 `@RequestPart`에 맞게 수정 (#93)

* **주요 내용**

  * 로그인 완료 시 **메인 페이지로 이동 경로 수정**
  * **쿠키 → LocalStorage**로 토큰 저장/취득 로직 변경
  * 시/도 선택 시 시/군 미표시 문제 **프런트 로직 보정**
  * **이미지 미리보기** 기능 추가(클라이언트)
  * 사진 업로드 요청을 **백엔드 `@RequestPart` 규약에 맞게** 전송하도록 수정
* **테스트**

  * 웹 UI에서 지역 선택/미리보기/업로드 흐름 수동 검증

---

#### 2.3 feat: #95 모임 목록에 **방장 좋아요 수** 표시 기능 추가 (#96)

* **개요**

  * 메인 페이지 카드에 호스트의 **좋아요 수(`hostLikeCount`)** 표시
* **변경 사항**

  * `MeetingListItemDto.HostSummary`에 `hostLikeCount` 필드 추가
  * `MeetingService`에서 `meetingReviewRepository.countReviewByUserId` 활용해 값 집계 → DTO 매핑 시 초기화
  * 프런트: 응답에서 좋아요 수 추출하여 카드에 표시, 스타일 적용
  * **홈 주소가 `/`로 변경됨**에 따라 `MeetingController`의 목록 페이지 **뷰 라우팅 메서드 제거**
  * `main-page.js`의 불필요한 주석 코드 정리
* **테스트**

  * 카드 렌더링/빈 값/대량 목록에서의 성능 수동 점검

## ✅ 오늘의 주요 결정 사항

* **토큰 저장소**는 **LocalStorage** 기준으로 통일(만료/로그아웃 처리 가이드 문서에 포함).
* **마이페이지 수정**은 부분 업데이트(필드별)에 한정, 서버는 빈/동일 값 무시 정책 적용.
* **목록 카드**에 `hostLikeCount` 노출 유지, 성능 영향은 배치/캐싱 검토 후 보완.
* **장소 표기**는 `광역시/도 + 시/구/군` 통일, 상세/목록 동일 규칙 적용.
* **라우팅**: 홈은 `/`, 목록 뷰 라우팅은 Controller에서 제거하고 **프런트 전담**.
